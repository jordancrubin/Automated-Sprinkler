OpenWeatherMap API Key

The OpenWeatherMap (OWM) API Key is required to fetch local weather data and forecast information. This allows the system to display current conditions and intelligently delay sprinkler runs based on the chance of rain.

You can get a free API key by signing up at openweathermap.org.

Rain Cutoff Percentage

This setting determines the threshold for the "Chance of Rain" forecast that will trigger a rain delay.

If the OpenWeatherMap forecast predicts a probability of precipitation (POP) greater than or equal to this value for the next 24 hours, the system will automatically skip scheduled runs to conserve water.

Default is 75%.

Weather Location

Enter your location to fetch local weather data. This is used to determine if scheduled runs should be skipped due to rain.

Format: City,CountryCode (ISO 3166)

Examples:
London,UK
Paris,FR
New York,NY,US

Firebase Configuration

Firebase Realtime Database is used to store historical data, logs, and water usage metrics in the cloud.

Firebase URL: The URL of your Realtime Database (e.g., https://your-project.firebaseio.com).

Firebase Secret: The database secret (Legacy Token) found in Project Settings > Service Accounts > Database Secrets.

Zone Port Configuration

The Port corresponds to the specific output pin on the PF575 I2C GPIO Expander board used to control the solenoid for this zone.

Valid Range: 1 through 16.
